# LinearRegression
Linear Regression Simulator

dotnet build 

dotnet run --project src/LinearRegression.Web

Use **Add** to upload a `.csv` file or paste comma- or tab-separated X/Y values. Data may include a header row with any column names; the first column is read as X and the second as Y. Numeric values are parsed with invariant formatting. Use **Export PDF** and choose **Save as PDF** in the browser's print dialog to export the chart and all data points.
