# LinearRegression
Linear Regression Simulator

dotnet build 

dotnet run --project src/LinearRegression.Web

Use **Add** to upload a `.csv` file or paste comma- or tab-separated X/Y values. Data may include an `x,y` header, and numeric values are parsed with invariant formatting. Use **Export PDF** and choose **Save as PDF** in the browser's print dialog to export the chart and all data points.
